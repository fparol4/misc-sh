# Development Commands
- **Formatting**: Run `stylua .` from the root directory to format Lua files.
- **Plugin Management**: Inside Neovim, use `:Lazy` to manage plugins (install, update, sync).
- **LSP/Tool Management**: Inside Neovim, use `:Mason` to manage LSP servers, linters, and debuggers.

# Common Operations
- Check health: `:checkhealth`
- Update LazyVim: `:Lazy update`
- View keymaps: `:FzfLua keymaps` (assuming FZF extra is active) or `:verbose map`.
