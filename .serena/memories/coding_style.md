# Coding Style
- **Indentation**: 2 spaces (`indent_type = "Spaces"`, `indent_width = 2`).
- **Column Width**: 120 chars.
- **Formatter**: Stylua (`stylua.toml` present).

# Conventions
- Follows LazyVim standard structure.
- Plugins are defined in `lua/plugins/` and automatically imported by `lua/config/lazy.lua`.
- Core settings are isolated in `lua/config/`.
